Dual Architecture

OpenCode-Style Dual Modes: ⚡ BUILD vs 📋 PLAN

Engineered to provide the freedom of autonomous agentic development while keeping high-stakes codebases safe.

Default Mode
⚡

BUILD Mode

Switch command: /build or /mode

Full autonomous full-stack developer. Can create files, directories, refactor legacy code, install npm dependencies, and run test suites.

  • write_file: Creates & edits project files
  • run_command: Runs build tools, npm, and git
  • Safety verification before file write or command execution
  • "Yes to all" session approval for high-speed workflows
Safe Mode
📋

PLAN Mode

Switch command: /plan or /mode

Read-only Senior Software Architect. Thoroughly investigates directory structures and reads code without risking any accidental edits.

  • list_files & read_file enabled for exploration
  • write_file & run_command strictly disabled
  • Produces detailed step-by-step implementation plans
  • Perfect for code reviews, architecture discussions, and audits

Command & Slash Command Reference

banglacli CLI v1.2.0
Command Type Description
banglacli Terminal CLI Starts the trilingual interactive AI coding session.
banglacli config Terminal CLI Runs the interactive provider, model & API key setup wizard.
banglacli list-models Terminal CLI Displays free Gemini & OpenRouter models with context limits.
/mode, /plan, /build Chat Slash Command Switches between autonomous BUILD mode and read-only PLAN mode.
/model Chat Slash Command Interactive menu to switch the active AI model on the fly.
/clear Chat Slash Command Clears the conversation context window and terminal screen.
/exit, /quit Chat Slash Command Safely terminates the session and returns to normal terminal.
