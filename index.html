Dual Architecture

BUILD Mode vs PLAN Mode

Inspired by OpenCode, BanglaCLI lets you choose between autonomous hands-on building and safe senior architectural reviews.

Default Mode
⚡

BUILD Mode

Command: /build or /mode

Full autonomous developer. Capable of creating files, refactoring legacy functions, running shell scripts, and building projects.

  • write_file: Creates & updates files and directories
  • run_command: Runs terminal commands (npm, git, test)
  • Interactive confirmation with [a] session approval
Safe Architect
📋

PLAN Mode

Command: /plan or /mode

Read-only Senior Software Architect. Safely audits directory structures, reads code, and formulates step-by-step blueprints without altering files.

  • list_files & read_file enabled for exploration
  • write_file and run_command strictly disabled
  • Drafts architectural roadmaps and migration plans

Command & Slash Command Reference

banglacli CLI v1.2.0
Command Type Action
banglacli Terminal CLI Starts the trilingual interactive coding session.
banglacli config Terminal CLI Runs the interactive setup wizard to select provider & key.
banglacli list-models Terminal CLI Displays free Gemini & OpenRouter models with token context limits.
/mode, /plan, /build Chat Slash Command Switches between autonomous BUILD mode and read-only PLAN mode.
/model Chat Slash Command Interactive menu to switch the active AI model on the fly.
/clear Chat Slash Command Clears the conversation context window and terminal screen.
/exit, /quit Chat Slash Command Safely terminates the session and returns to normal terminal.
