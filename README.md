## 🌟 Overview

This repository hosts the official landing page and interactive documentation for **BanglaCLI** (`banglacli`), an autonomous, serverless AI coding agent for the terminal that understands **বাংলা (Bangla)**, **Banglish**, and **English** naturally.

### Key Highlights of the Website:
- ⚡ **Interactive Terminal Simulator**: Try out BanglaCLI right in your web browser with realistic scenarios (Bangla prompt, Banglish prompt, English prompt, and PLAN mode audit).
- 📋 **OpenCode-Style Build & Plan Modes Showcase**: Comprehensive breakdown of autonomous BUILD mode vs safe read-only PLAN mode.
- 🔑 **Free AI Provider Matrix**: Direct links and instructions to connect Google Gemini (15 RPM free tier) and OpenRouter free models without paying a dime.
- 👨‍💻 **Developer Spotlight**: Built with passion by **Rakib Hasan Shuvo**.
- 📱 **Mobile & Desktop Responsive**: Built with modern CSS glassmorphism, responsive grid layouts, and zero heavy dependencies.

## 🚀 Quick Start for BanglaCLI CLI

To install and run the actual BanglaCLI coding assistant in your terminal:

```bash
# Global installation via npm
npm install -g banglacli

# Or run instantly without installing
npx banglacli
```

---

## 🛠️ Local Development for Website

To run this website locally on your machine:

```bash
# 1. Clone the repository
git clone https://github.com/rakibhasanshuvo712-hub/banglacli-website.git
cd banglacli-website

# 2. Start a local HTTP server
npx serve .
# or
python -m http.server 3000
```

Open `http://localhost:3000` in your web browser.
